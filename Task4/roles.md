# Роли для доступа к кластеру Kubernetes

Ресурсы в кластере разделены по доменам компании. У каждого домена свой namespace:
`sales` (продажи), `housing` (ЖКУ), `finance` (финансы), `data` (данные).

| Роль | Права роли | Группы пользователей |
|------|------------|----------------------|
| cluster-viewer | Только просмотр ресурсов во всём кластере (поды, сервисы, деплойменты, configmap, логи и т. п.). Секреты смотреть нельзя | `viewers` — владельцы продуктов, бизнес-аналитики, менеджеры операционных команд |
| cluster-configurator | Настройка кластера: создание, изменение и удаление ресурсов (деплойменты, сервисы, configmap, ingress, namespace и т. п.). Секреты смотреть нельзя | `devops` — DevOps-инженеры и инженеры по эксплуатации |
| domain-developer | Работа только в namespace своего домена: просмотр и изменение подов, деплойментов, сервисов, configmap, просмотр логов. Секреты смотреть нельзя | `sales-team`, `housing-team`, `finance-team`, `data-team` — разработчики доменов |
| security-auditor | Привилегированная роль: просмотр всех ресурсов кластера, включая секреты, роли и привязки ролей. Изменять ничего нельзя | `security` — специалист по ИБ |
| cluster-admin | Полный доступ ко всему кластеру (встроенная роль Kubernetes) | `admins` — администраторы платформы |
